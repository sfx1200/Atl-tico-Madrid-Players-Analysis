# ⚽ Atlético Madrid Players Analysis Dashboard

A comprehensive, interactive dashboard for analyzing Atlético Madrid player performance during the 2024-25 season.

## 🚀 Features

- **Overview Section**: Team statistics, top scorers, goal contributions, squad distribution
- **Attackers Analysis**: Goals, assists, chances created
- **Midfielders Analysis**: Passing accuracy, duels won
- **Defenders Analysis**: Tackles, interceptions
- **Player Comparison**: Interactive player profiles with radar charts and detailed statistics

## 📦 Installation
```bash
# Clone the repository
git clone <your-repo-url>

# Navigate to project directory
cd atletico-madrid-dashboard

# Install dependencies
npm install

# Start development server
npm start
```

## 🌐 Deployment

### Deploy to Vercel (Recommended)
```bash
npm install -g vercel
vercel
```

### Deploy to Netlify
```bash
npm run build
# Then drag and drop the 'build' folder to Netlify
```

## 🛠️ Technologies

- React 18
- Recharts (Data Visualization)
- Lucide React (Icons)

## 📊 Data

Real player statistics from the 2024-25 La Liga season including:
- Goals, Assists, Matches, Minutes
- Pass Accuracy, Duels Won
- Tackles, Interceptions
- Player Ratings
